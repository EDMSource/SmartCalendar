# SmartCalendar

Умный календарь для Android с заметками и цветовыми темами.

[![Версия](https://img.shields.io/badge/version-1.0.0-blue)](#)

---



## Функции

### Основные возможности
* Календарь с возможностью удобного переключения месяцев
* Создание, редактирование и хранение заметок на каждый конкретный день
* Быстрый поиск по всем созданным заметкам

### Интерфейс и кастомизация
* 15 встроенных цветовых тем (включая темы Сакура, Космос, Северное сияние)
* Системная тёмная тема для комфортного использования в ночное время
* Игровая механика: интерактивная рулетка для разблокировки новых тем

### Стабильность
* Интегрированная система автоматической отправки логов об ошибках в Telegram

## Технологии и стек

При разработке приложения использовались современные компоненты разработки под Android:


| Компонент                  |  Технология / Библиотека     |
| :---                       | :---                         |
| **Язык программирования**  | Kotlin                       |
| **UI-фреймворк**           | Jetpack Compose / Material 3 |
| **Асинхронность**          | Coroutines                   |
| **Хранение данных**        | DataStore / Gson             |
| **Сетевой слой**           | OkHttp                       |

## Инструкция по установке

1. **Готовая версия приложения:** [Скачать APK]([https://github.com](https://github.com/EDMSource/SmartCalendar/releases/tag/v1.0.0) текущего репозитория и скачайте актуальный APK-файл.
2. Перед запуском файла убедитесь, что в настройках операционной системы устройства разрешена установка приложений из неизвестных источников.
3. Откройте загруженный файл и подтвердите установку приложения.

## Руководство пользователя

### Навигация и календарь
Для просмотра смежных периодов используйте стрелки переключения месяцев. Чтобы создать или просмотреть запись, нажмите на соответствующую ячейку дня в сетке календаря.

### Настройка внешнего вида
Перейдите в меню конфигурации, нажав на иконку шестерёнки. В открывшемся окне доступны параметры переключения на тёмную тему и выбор доступных цветовых палитр.
